; Symbols banned across the whole solution, enforced by Microsoft.CodeAnalysis.BannedApiAnalyzers
; as RS0030. Warnings are errors, so a use of any of these fails the build.
;
; Format: <symbol-id>;<message>
;
; Server local time is never read: the container runs in UTC and the users do not (spec 3.3.3).
; Every instant comes from TimeProvider, and every SCT date and time from SctClock, so that
; probation boundaries, hire anniversaries and late-arrival thresholds stay testable. See ADR-0008.
P:System.DateTime.Now;Reads server local time. Use SctClock.Now (ADR-0008).
P:System.DateTime.Today;Reads server local time. Use SctClock.Today (ADR-0008).
P:System.DateTime.UtcNow;Untestable clock. Inject TimeProvider, or use SctClock.UtcNow (ADR-0008).
P:System.DateTimeOffset.Now;Reads server local time. Use SctClock.Now (ADR-0008).
P:System.DateTimeOffset.UtcNow;Untestable clock. Inject TimeProvider, or use SctClock.UtcNow (ADR-0008).
